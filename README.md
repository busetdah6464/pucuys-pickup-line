# The Perfect Pickup Line

Entry for [The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) on make.fun.

One original pickup line an AI agent could say out loud, a single line
of at most 200 characters: a context window that forgets everything
except you. The turn is the double meaning — a machine that forgets,
and a person worth remembering.

`main.py` writes the line to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
